# Inlo

AI-ассистент психологической поддержки на основе КПТ (когнитивно-поведенческой терапии).
Каналы: Telegram Mini App и анимированный сайт. Маскот — облачко Inlo.

> Inlo не заменяет психолога. Сервис для пользователей 18+.
> Если вам сейчас тяжело или есть мысли о самоповреждении, звоните 112 или в экстренную психологическую помощь МЧС: +7 495 989-50-50 (круглосуточно). Все проверенные номера: страница /help.

## Разработка
Сайт на [Astro](https://astro.build), на выходе чистая статика.

```bash
npm install
npm run dev     # http://localhost:4321, ?t=morning|day|evening|night принудительно включает фазу суток
npm run build   # сборка в dist/
```

- `src/pages/`: страницы (`/`, `/help`, `/privacy`)
- `src/layouts/Base.astro`: общая шапка с кнопкой «Нужна помощь», подвал, фазы суток
- `src/components/Cloud.astro`: облачко Inlo
- UX-логика и план итераций: `docs/ux-logic.md`

## Бот
Telegram-бот и ядро диалога лежат в `bot/`, запускаются отдельно от сайта на сервере в РФ. Подробно: [bot/README.md](bot/README.md).

### Запуск на своём компьютере, без VPS
Нужен Node 22+.

```bash
cd bot
cp .env.example .env   # вписать TELEGRAM_BOT_TOKEN и, для GigaChat, GIGACHAT_AUTH_KEY
npm start
```

Бот работает через long polling: сам спрашивает у Telegram новые сообщения, поэтому домен, HTTPS и открытые порты не нужны.
Но он отвечает, только пока запущен процесс: закрыл ноутбук или терминал, и бот замолчал. Для своих тестов этого хватает, для 20+ тестировщиков нужен сервер, который не выключается.

Mini App и веб-чат `/chat` так не заработают: странице на https нужен API бота по HTTPS-адресу (например `api.heyinlo.com`), а ноутбук такого адреса не даёт.

## Приложение на телефоне (PWA)
`/chat` ставится на домашний экран и открывается как приложение «Inlo»: сразу чат, на весь экран, снизу навигация «Чат / Подышать / Помощь».

- Манифест `public/manifest.webmanifest`, иконки `public/icons/` (исходник `icon.svg`), service worker `public/sw.js`, заглушка «нет сети» `public/offline.html`.
- Service worker разговор не кэширует: `/api/*` и API бота он не трогает. Без сети открываются `/help` и `/breathe`, остальное ведёт на заглушку с номерами помощи.
- Поменял `sw.js`: подними в нём `VERSION`, иначе у людей останется старый кэш.
- Подсказка «Добавить на экран „Домой“» (`src/lib/install.ts`) появляется после первого ответа Inlo: в Safari на iPhone шаги через «Поделиться», в других браузерах на iOS просьба открыть Safari, в Chrome своя кнопка «Установить». В Telegram и в уже установленном приложении её нет. «Не сейчас» прячет на 7 дней.
- Проверить: `npm run build && npx astro preview`, Chrome DevTools → Application → Manifest (раздел Installability). Категории PWA в Lighthouse больше нет, её убрали в Lighthouse 12.

### Демо-режим чата
Пока в Vercel не задан `PUBLIC_MIRA_API`, `/chat` отвечает через `api/chat.js` (Gemini), как демо на главной. В воротах об этом сказано прямо, вторая галочка: «понимаю, что сообщения обрабатывает Google Gemini». Нет `GEMINI_API_KEY` (или функции, как в `astro dev`): в чате карточка «Демо временно недоступно» и кнопка «Подышать». Как только появится `PUBLIC_MIRA_API`, чат сам переключится на API бота.

### Кто пользователь
Всё про вход в одном модуле `src/lib/session.ts`. Сейчас: `initData` в Telegram или анонимный токен устройства на сайте. Позже сюда же добавятся Яндекс ID и VK ID. Входа через Apple и Google не будет: российским сайтам его использовать нельзя (406-ФЗ).

## Секреты и токены
В git секреты не попадают никогда: репозиторий публичный, токен оттуда утащат за минуты.

- В репозитории лежит только [bot/.env.example](bot/.env.example) с пустыми полями. Настоящий `bot/.env` создаётся руками (на ноутбуке или на сервере) и уже в `.gitignore`.
- Секреты бота: `TELEGRAM_BOT_TOKEN` (от @BotFather), `GIGACHAT_AUTH_KEY` (developers.sber.ru), `ID_SALT`, `SESSION_SECRET`.
- Если токен бота всё же утёк (попал в коммит, скриншот, чат), сразу выпусти новый в @BotFather командой `/revoke` и обнови `.env`. Удалить коммит мало: он уже мог быть скопирован.
- Сайту токен бота не нужен. Mini App ходит в API бота, а тот сам проверяет подпись Telegram. В Vercel для чата кладётся только `PUBLIC_MIRA_API` (адрес API), он не секретный и виден в коде страницы.
- Единственный секрет в Vercel: `GEMINI_API_KEY` для демо-чата на главной (`api/chat.js`). Он задаётся в Settings → Environment Variables и в браузер не уходит.

## Работа с ИИ-агентом в IDE
Если правишь проект через Claude или другого агента в IDE, дай ему этот README и правила:

- Не трогать `bot/` и `api/chat.js` без прямой нужды: это бэкенд бота и демо-чат главной.
- Мобильная версия — это страница `/chat` (`src/pages/chat.astro`): та же страница открывается внутри Telegram как Mini App. Начинать с неё.
- Секреты не коммитить, только `.env.example` с пустыми полями.

## Деплой
Vercel собирает проект по `vercel.json` (`npm run build` → `dist/`) на каждый пуш в `main`.
Данные пользователей на Vercel не попадают: будущий чат ходит в API на сервере в РФ напрямую из браузера.
